Your safe room

Add assistants. Keep your computer protected.

Assistants work inside a sealed workspace. They can only reach your files, websites, and commands through OneBridge — with a private key for each assistant. Day-to-day use the OneBridge desktop app (npm run app): workspace view and AI policies in one window.

Prefer the Electron app for Policies + desktop together. This page is a host-only control plane fallback for install and debugging.

What stays protected

Built for people who want AI help without opening the whole machine.

  • Each assistant has its own private access key
  • Internet from the workspace goes through OneBridge
  • Your project files are not copied into the workspace
  • You can remove an assistant completely in one click
